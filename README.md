# 暗面三部曲 · Dark Trilogy

三组颜色、三种情绪，全部用纯代码画出来。整体走**版画语言**：每张只用三色，明暗过渡全靠有序抖动的网点，像一本暗黑铜版画册。

| 幕 | 情绪 | 颜色 | 人类参考 | 状态 |
|---|---|---|---|---|
| 第一幕《糜烂》 | 黑暗、糜烂、丧 | `#000030` `#610070` `#18a69a` | 蚀刻版画 × 贝克辛斯基 | 待画 |
| 第二幕《机械解剖》 | 爱、死亡、机器人 | `#161a24` `#9aa9ad` `#401720` | 达芬奇式解剖图版 | 待画 |
| 第三幕《无声》 | 无自由、禁锢、微弱的光、挣扎、无声 | `#17252d` `#75d6f2` `#ff002b` | 皮拉内西《想象的监狱》× 卡拉瓦乔 | v1 |
