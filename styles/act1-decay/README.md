# 第一幕《糜烂》v3 · 玫瑰

- **情绪**：黑暗、糜烂、丧
- **颜色**：`#000030` 底 · `#610070` 淤紫 · `#18a69a` 腐烂荧光
- **人类参考**：蚀刻版画（用酸腐蚀铜板）× 贝克辛斯基

## 技法要点
1. 主体：一朵垂头的玫瑰。30 片花瓣按黄金角由外向内叠，花头压扁表示往前垂；每瓣卷起的瓣缘更亮、瓣心发暗，瓣间留黑缝，花心一圈螺旋
2. 弯下去的带刺的茎、两片耷拉的叶子、地上几片落瓣；轻度域扭曲，保住玫瑰的形
3. 霉斑：Gray-Scott 反应扩散（1/3 分辨率跑 5000 步再放大）；进料率随位置变化，有的地方长斑点、有的地方长菌丝；人形外杀死率高，霉只长在身上
4. 淤紫是肉身（噪声明暗 + 霉斑），再随机腐蚀出小坑
5. 荧光青只取霉斑的边缘（V 的梯度），并且只成片出现，不撒满
6. v3：花瓣散落一地 + 几片正在往下飘（单独一层，保证看得见）；霉斑更多、吃黑的地方更大；青色腐液从花头底部粗细不一地往下淌，末端成滴，地上积一滩
7. 融化：下半身的像素沿部分列往下拖拽，拉成细长的滴痕，底部淤积成一滩
7. 空中漂浮少量孢子；颗粒只落在亮处，暗部保持干净
8. 三色 8×8 Bayer 抖动，2px 网点
