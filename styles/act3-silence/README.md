# 风格三（草案）·《无声》

> 名字和定义待绮思确认，这里是澜的第一版提案。

- **情绪**：无自由、禁锢、微弱的光、挣扎、无声
- **颜色**（只用这三色）：`#17252d` 底 · `#75d6f2` 微光 · `#ff002b` 挣扎
  （原稿写作 `#ffOO2b`，按 `#ff002b` 处理）
- **人类参考**：皮拉内西《想象的监狱》（铜版画）× 卡拉瓦乔明暗法
- **画法逻辑**：美柔汀（mezzotint）——深色底上「刮」出光

## 技法要点
1. 一点透视的无尽拱廊 + 往上的楼梯，墙面用汇聚刻线
2. 前景牢笼栏杆：纯黑剪影，只在朝光一侧留一丝冷边
3. 高窗斜射的体积光：光锥渐宽、窗格条纹、浮尘亮点、地面光斑
4. 挣扎：光斑里一个小笼子，一粒红点随机游走、不断撞墙，轨迹由淡到亮；远处几粒快熄灭的红
5. 大面积留黑：「无声」靠空白表达
6. 三色有序抖动：8×8 Bayer，2px 网点；轻胶片颗粒 + 暗角

## 运行

```bash
pip install numpy pillow
python styles/act3-silence/act3_silence.py 7   # 参数是随机种子
```

示例：`examples/act3_silence_s7.png`

## FIG. II《蔓延》· `act3_veins.py`（seed 7）
接着第一张的故事：光更弱了，小笼子的一根栏被撑断，笼里空了。红线从缺口爬出来，背离灭点往镜头方向蔓延，爬满内壁和天花板，最后缠上镜头前的栏杆。
- 光：体积光与地面光斑压到约一半，浮尘减少；建筑只留拱框，透视排线几乎隐去
- 红线：递归分叉的随机游走，离灭点越远越粗越亮（透视），远处淡成网点
- 前景栏杆：每根两条红藤自下而上攀爬，偶尔斜跨一道，伸出细须

```bash
python styles/act3-silence/act3_veins.py 7   # → act3_veins_s7.png
```
示例：`examples/act3_veins_s7.png`
