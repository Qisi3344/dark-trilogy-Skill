# 第二幕《机械解剖》v1

- **情绪**：爱、死亡、机器人
- **颜色**：`#161a24` 底 · `#9aa9ad` 金属灰 · `#401720` 锈血
- **人类参考**：文艺复兴解剖图版、达芬奇手稿

## 技法要点
1. 心形参数曲线做轮廓；用到边缘的距离当高度，算出受光面（光从左上）
2. 外壳是铜版刻线：两组斜向排线沿曲面弯曲，越亮越密，暗部加第二组交叉线
3. 左半边剖开：露出五个齿轮（齿形 + 轮毂 + 辐条）和细导线；剖口边缘画出壳的截面厚度
4. 顶部伸出五根铜管当主动脉，双线成管、环箍、插头
5. 沿轮廓一圈铆钉；编号引线 + 拉丁文/中文图注 + 双线图版框，「TAB. II · COR MACHINAE · FIG. I 机械之心」
6. 锈血只从右侧一道裂缝渗出：裂缝刻深，血痕往下淌、末端成滴，周围晕开
7. CRT 扫描线（每 4px 一道暗线）+ 只落在线稿上的颗粒 + 极稀的铁屑点
8. 线稿保持锐利直接上色，明暗走 8×8 Bayer 抖动

# FIG. II《穿心》

一颗铆钉铁壳的心被一把剑斜着扎穿，背后张开天使羽翼，心口凹处开着一朵玫瑰，锈血从剑进出的两处伤口往下淌，几片羽毛在落。圣心图像 × 解剖图版。

- 羽翼：三层羽毛由上往外扇形展开，外层长而暗、内层短而亮，圆头羽形 + 羽轴
- 剑：沿剑轴坐标画刃、中脊、剑格、缠绳握把、圆形剑首；刃在心里那段不画（穿过去）
- 遮挡：先画羽毛线稿，再用心和剑的轮廓把底下的线「挖黑」，最后画前景线
- 伤口：自动求剑轴与心轮廓的交点，在两处各渗出一摊血和滴痕；心下那截刃沾血
- 玫瑰：16 瓣黄金角叠放 + 花心螺旋，茎插进心口凹处，两片叶子

```bash
python styles/act2-anatomy/act2_pierced.py 11
```
