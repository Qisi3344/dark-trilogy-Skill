# 配色 5 ·《咒火》

`#0b1019` 夜黑底 · `#bc9800` 暗金（火）· `#d900ff` 电紫（诅咒）

火刑柱上被吊起双手、仰头尖叫的女人。她是女巫还是普通人，无人知道；但怒意到了顶点，紫色的诅咒从她张开的嘴里升起，在天上结成符文之环，又像灰一样落回围观者头上。

参考：猎巫时代的木刻传单 × 戈雅。

- 火：竖向拉长的湍流噪声 + 域扭曲，一条条火舌往上舔，越高越窄；火光映亮的烟作剪影背景
- 人：几何剪影钉死形体（吊绑的双臂、弓起的躯干、后仰的侧脸、往上卷的长发），只靠金色轮廓光显形，脸始终在黑里
- 诅咒：唯一的紫色焦点在嘴里，螺旋咒烟 → 符文环 → 紫灰落在人群头顶
- 前景人群黑剪影，柴堆、绳子只被火光勾出边
